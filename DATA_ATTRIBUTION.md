# Data Attribution and Reuse

## Source

The versioned data snapshot in this repository originates from the U.S. Energy Information Administration (EIA) Open Data API, Electricity Retail Sales dataset:

- Source organization: U.S. Energy Information Administration
- Dataset: EIA-861M monthly electricity retail sales
- API endpoint: `https://api.eia.gov/v2/electricity/retail-sales/data/`
- Coverage requested: 2016-01 through 2025-12
- Historical snapshot acquisition: 2026-09-16
- Source page: https://www.eia.gov/opendata/browser/electricity/retail-sales

Suggested acknowledgment:

> Source data: U.S. Energy Information Administration, EIA-861M monthly electricity retail sales, API snapshot acquired September 16, 2026.

EIA states that its government publications and data products are in the public domain and may be used or distributed with acknowledgment. API use remains subject to EIA's terms. See:

- https://www.eia.gov/about/copyrights_reuse.php
- https://www.eia.gov/opendata/terms-of-service.php

The EIA name identifies the data source only. It does not imply that EIA endorses this portfolio project. The EIA logo is not used.

## Repository Files

`data/raw/eia861m_retail_sales_2016_2025.csv` preserves the API response table used by the project. `data/interim/eia861m_retail_sales_2016_2025_with_quality_flags.csv` is a derived artifact generated by the repository's validation code. The added quality and consistency fields are project-derived and must not be represented as EIA-provided classifications.

Acquisition metadata, validation metrics, and SHA-256 checksums accompany the snapshot under `artifacts/`. These files establish which snapshot supports the documented December 2025 analysis. A fresh API request may return revised values.
